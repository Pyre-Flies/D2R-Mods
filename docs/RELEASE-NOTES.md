Close the game before replacing DLLs and keep one active copy of each plugin (remove legacy `unhoarder.dll` when installing `pyre-lootfilter.dll`). Existing settings and `filter.json` files are preserved.

Automated build, unit, and packaging checks pass across all ten first-party plugins and the Buff HUD companion, and Pyre Loot Filter, Controller QOL rev.95, and Buff HUD 1.1.2 were validated live in D2R Reimagined.
