# D2R Mods - 2026.10.29.1

- **Pyre Stash Search 1.3.1+rev.1:** Adds instant cross-page search across your Personal Stash and all Shared Stash pages without modifying UI layouts or MPQ files. Supports boolean operators (`&`, `|`, `-`, `!`), quality/flag/socket/stat shorthands (`uni`, `set`, `rw`, `eth`, `0os`–`6os`, `fcr`, `ias`, `fhr`, `mf`, `allres`, `cb`, `ds`, etc.), active-page gold border/tint item highlighting, an expandable Side Tab Flyout (`[<]` / `[>]`) with right-click custom tab names saved in `plugins.toml`, `/<page>` quick jumps, and `Ctrl` / `Ctrl+Shift` + Mouse Wheel tab switching.
- **Running Defense 1.3.1+rev.1:** Replaces vanilla D2R's 100% running Defense loss (`PLRMODE_RUN`) and melee running auto-hit with a configurable percentage penalty (`defense_loss_percent` in `d2rloader/config/running-defense.toml`, default `30`), displays your actual running Defense value on the Character Sheet instead of `"---"` along with an always-visible running indicator icon inside the `ArmorClass` box, and includes an optional running Shield Block penalty override (`override_block_penalty`, `block_loss_percent`) plus `/runningdefense [status]` console diagnostics.
- **Item Roll Ranges 1.3.1+rev.56:** Attributes permanent set (`[Set]`), crafted-recipe (`[Craft]`), and identified enchantment (`[E]`, including multi-step `419`/`420` upgrades) contributions alongside unique, affix, runeword, socket, and corruption sources; expands combined-stat breakdowns (`ContributionModel`) to cover block chance, maximum resistance bonuses, faster cast rate, crushing blow, deadly strike, open wounds, mana after kill, all-skills, and elemental mastery/pierce stats; and maps two-handed weapon min/max damage property targets (`23`/`24`).
- **Pyre Loot Filter 1.3.1+rev.2:** Aligns plugin version metadata to `1.3.1+rev.2` with all equipment tier filtering (`conditions.tier`: `"normal"`, `"exceptional"`, `"elite"`), native ground-label border rendering (`tooltip.borderColor`), 12 minimap marker shapes, custom drop sounds (`Reimagined.mpq/data/` sound table and `Filter01.flac`–`Filter16.flac`), mouse pickup guard with `Ctrl` override, always-pickup Gold preservation, live auto-reload, `/filter` chat commands, and Controller QOL visibility interop.
- **Buff HUD 1.3.1+rev.3 (Companion):** Adds joined-game and dedicated-server (`d2rds`) multiplayer buff timer synchronization, a per-character Blood Golem (`blood_mana`) aura opt-out checkbox (`AuraCheck` in slot 0 and `buff-blood-aura [status|on|off]` console command), hover tooltips and quick-cast bar clearance (`BuffGrid` `y = -665`), party shout icon fallbacks, and fixes for stuck item-granted buff timers alongside automatic runtime Excel buff catalog discovery and 25 Hz frame-time gating.

Close the game before replacing DLLs and keep one active copy of each plugin (remove legacy `unhoarder.dll` when installing `pyre-lootfilter.dll`, and remove legacy `d2rl-buff-panel.dll`/`d2rl-buff-panel.mpq` when installing `d2rl-buffhud.dll`/`d2rl-buffhud.mpq`). Existing settings and `filter.json` files are preserved.

Automated build, unit, artifact, and packaging checks pass across all twelve first-party plugins and the Buff HUD companion, and the updated plugins (`Pyre Stash Search`, `Running Defense`, `Item Roll Ranges`, `Pyre Loot Filter`, and `Buff HUD`) were validated live in D2R Reimagined.
