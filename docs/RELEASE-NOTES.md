# D2R Mods - 2026.11.14.1

Updates **Inventory Deposit** (`1.3.1+rev.16`) and **Controller QOL Updates** (`1.3.1+rev.97`) with third-party and Reimagined companion plugin compatibility fixes, full-stack deposit handling, and a rejuvenation potion deposit toggle:

- **Fix 'Deposit All' getting blocked alongside sound and companion plugins:** Clicking 'Deposit All' (or running bulk stash on controller) won't get disabled mid-session or refuse clicks when another plugin hooks game audio (such as sound-muting or drop-alert plugins), whether you're running **Universal Chain Hook** or not. Both plugins also work cleanly alongside offline and Ladder builds of `d2rl-global-chat.dll` and `d2rl-maps.dll`, and **Inventory Deposit** no longer logs a false-alarm UI scheduling warning during game startup.
- **Skip full advanced-stash stacks instead of stopping the batch:** When a rune, gem, or material stack in your advanced stash hits its cap (or hits a lower server stack cap online), **Inventory Deposit** and **Controller QOL Updates** now skip just that maxed-out item type and keep depositing everything else in your inventory. Once every remaining eligible item in your inventory belongs to a full stack, the 'Deposit All' button greys out cleanly.
- **Toggle rejuvenation potion depositing (`/autodeposit rejuv`):** Added `deposit_rejuvenation_potions = true` in `inventory-deposit.toml` and `/autodeposit rejuv [on|off|toggle|status]` in game chat (plus an 'Options -> Gameplay -> UI -> Deposit Rejuvenation Potions' toggle when running Reimagined's settings menu) so you can keep rejuvenation potions in your main inventory when clicking 'Deposit All'.
- **Full runtime suite included:** Bundles **Inventory Deposit `1.3.1+rev.16`**, **Controller QOL Updates `1.3.1+rev.97`**, **Universal Chain Hook `1.3.1+rev.7`**, **Pyre Performance Optimizations `1.3.1+rev.2`**, all remaining PyreFly plugins, **Buff HUD `1.3.1+rev.3`**, and a complete `SHA256SUMS` manifest. Keep the `00-` prefix on `00-d2rl-chain-hook.dll` so D2RLoader loads it first.

Ran through the unit, companion coexistence, artifact, and packaging checks locally, and verified the 'Deposit All' compatibility fixes in-game.
