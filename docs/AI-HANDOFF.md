# Agent entry point

Read [AGENTS.md](../AGENTS.md), then the affected plugin's `DEVELOPMENT.md`.
The [documentation map](README.md) routes to current feature contracts and build procedures.
Current versions and downloads are listed once in the [repository README](../README.md).

Search the owning source and tests first. Follow a feature record only when the
change depends on its native contract. Confirm build identity and executable guards;
keep automated, installed and live-game evidence separate.

The former broad handoff is retained in
[history](history/AI-HANDOFF-before-reorganization.md). It records earlier builds
and is not a current release summary.
