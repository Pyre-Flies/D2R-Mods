# User documentation convention

Each plugin's README.md is its complete user reference: purpose, installation,
all commands/controls, accepted configuration keys and editing examples. Runtime
packaging reads this same file, keeps local section anchors and expands relative
repository links for readers opening the ZIP independently. Required notices
are appended to the README. Keep technical/build procedures in separate records.

The release overview lists command examples per plugin. Controller QOL links to
its full README without duplicating its extensive button/skill documentation.
List plugins with chat commands before Map Assistance and Inventory Deposit.
