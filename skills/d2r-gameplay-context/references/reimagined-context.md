# D2R Reimagined context

Read this whenever a request concerns D2R Reimagined. The mod intentionally preserves a recognizable Diablo II core while substantially changing classes, skills, items, crafting, drops, quality-of-life systems, and progression incentives.

## Do not reason from vanilla by default

Reimagined changes enough systems that a vanilla answer is only a comparison baseline. Verify, as applicable:

- available classes, skill trees, hard-point caps, prerequisites, synergies, formulas, and maximum character level;
- unique, set, runeword, base-item, socket, affix, and drop-table data;
- cube recipes, item crafting, enchantment, upgrades, rerolling, corruption, orbs, and pliers;
- rune/gem/item stacking and dedicated storage systems;
- terror-zone, rune-boss, boss-first-kill, and difficulty-specific rewards;
- inventory or UI layouts and any mod-added tabs or panels;
- current patch behavior and whether a change affects existing items retroactively.

The current game-data site exposes a Reimagined skill planner and includes mod-added class content. Do not assume vanilla's seven-class model or 20-hard-point skill cap applies. Read the current planner for exact trees and calculations.

## Source roles

- **Official wiki:** player guides, system explanations, progression advice, patch notes, and historical context.
- **Official game-data site:** searchable current catalogs and calculators for skills, attack speed, drops, uniques, sets, runewords, item bases, affixes, cube recipes, and orbs.
- **Official mod repository:** source data and implementation details. Use it to resolve ambiguity, verify exact table rows, or understand behavior not fully exposed by the website.
- **Installed checkout:** the best evidence for what the user's local build contains, but record its version and revision before treating it as current upstream behavior.

## Version discipline

For precise answers, record at least one of:

- the version shown by the launcher or `modinfo.json`;
- a release/tag or patch-note version;
- the repository branch and commit;
- the date and URL of the live data page.

When sources disagree, do not silently merge them. Prefer the user's installed version for local behavior, explain the discrepancy, and identify whether the wiki or website appears ahead of or behind that version.

## Recommendations and build advice

Avoid importing vanilla build rankings, leveling routes, breakpoints, or farming advice without checking Reimagined data. Recommendations should account for the current skill planner, item ecosystem, crafting access, drop model, difficulty, player count, and whether the user is playing online/ladder or locally modified content.

Keep storyline identity separate from mechanical progression. Reimagined may preserve the familiar act narrative while changing the rewards, encounters, skills, items, and efficient route through it.
