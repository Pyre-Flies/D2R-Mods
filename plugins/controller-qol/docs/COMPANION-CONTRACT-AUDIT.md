# Companion contract audit - rev.79-beta.4

This is an inventory of current coupling, not a universal compatibility claim.
The aim allocation investigation found shared loader-resource pressure rather
than a Chat detour at the failed aim entry. The gem failure was an SDK-ineligible
display identity. Diagnose each boundary from its actual runtime evidence.

| Dependency | Current policy | Remaining qualification |
| --- | --- | --- |
| Global Chat non-chat sender | Complete owned forwarding graph, relocated references, exact original Core continuation; no companion file/version pin | Changed operative instructions or an unknown chain still refuse the affected remote action |
| Maps item quantity | Complete stat-70/layer-0 route, immutable tables, data ownership and Core continuation; no companion file/version pin | Restricted to item quantities; separate from the Chat proof |
| Auto Belt Refill stored placement | Existing exact file hash, full wrapper bytes at module `+0xB7F0`, trampoline pointer `+0x136438`, exact native tail and continuation | Still brittle to unrelated rebuilds; complete helper/observer/logging contract has not been requalified here |
| Potion Auto Pickup free-slot planner | Existing plugin ID/version `ruffneckk-potion-auto-pickup` / `1.3.3`, known detour shape and unchanged native tail | Actual tester DLL was not supplied in the original review and this plugin is absent from the current pack; do not erase the version requirement without equivalent proof |
| D2RCore private native interfaces | Exact Core artifact plus native entries/provider slots/layout witnesses | Keep exact-build admission: these are private provider/native contracts |
| Host/client shared-plugin identity | Loader's package fingerprint remains enforced | Both sides must load matching QOL; no environment-mismatch bypass |

The installed Auto Belt Refill artifact still matches its retained guard:
`77c7d1b9068c8cacc2fded62ff1120b441001d601ad65a8ee3043e3b61c650db`.
This is current artifact evidence, not proof of every live belt operation.

The two belt adapters still need separate work to eliminate their companion
identity pins. Auto Belt's wrapper includes observer and debug/logging helpers;
matching only its outer prologue or ignoring its checksum would weaken its
existing contract. Potion Auto Pickup's arbitrary version must not be admitted
on metadata alone. Keep these limitations visible in release review.

This revision contains belt-planner refusal to belt operations. It no longer
blocks independent gem/rune/material withdrawals to Inventory or Cube, or the
common selected-tab observation used to avoid an ordinary-stash fallback.

For future changes, prefer a supported versioned SDK/companion capability with
documented arguments, semantics, lifetime and ownership. In its absence, qualify
the entire reachable native path needed by QOL. Do not replace whole-file pins
with unchecked wildcard signatures, arbitrary detour following, or direct calls
to a private original trampoline. Keep no-retry confirmation, session identity,
destination/capacity and per-feature refusal tests.

The release gate remains the actual full plugin pack on both host roles:
startup/first join, failed join, disconnect/rejoin, delayed confirmation,
full/empty destinations, counter selection/tab/season changes, skill persistence
and native behavior with QOL disabled. A local TCP/IP test validates a separate
host process, but cannot establish the real remote server's latency or save
backend behavior. A candidate that passes unit tests is not a live-tested release.

That gate caught two Maps hook-allocation failures after beta.3 restored QOL aim.
Beta.3 remains unpublished. Beta.4 moves QOL's existing CALL relay allocations
away from the Core's narrow allocation range. The next local full-pack launch
installed QOL and both affected Maps hooks in both processes; the client had 59
free hook slots. Future packs still require capacity checks. This is resource
coexistence, independent of Chat/Maps code admission.
