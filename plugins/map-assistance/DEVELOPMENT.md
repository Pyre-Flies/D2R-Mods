# Map Assistance development

Read the [player README](README.md), [changelog](CHANGELOG.md),
[design](docs/DESIGN.md) and [compatibility notes](COMPATIBILITY.md).
Implementation/configuration are in `src/`; tests are in `tests/`.
Build and run CTest using [CONTRIBUTING.md](../../CONTRIBUTING.md).

This plugin supplies static Keys-tooltip guidance through public SDK services.
It does not inspect generated map seeds. Preserve that boundary and distinguish
user-confirmed visible tips from table coverage and automated checks.

Prior release and development records remain in [history](docs/history/README.md).
