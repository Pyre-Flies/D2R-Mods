# Credits

## Kryszard's PD2 Loot Filter

Map Assistance was made substantially easier by Kryszard's extensive work on
the map-reading assistance in
[Kryszard's PD2 Loot Filter](https://github.com/Kryszard-POD/Kryszard-s-PD2-Loot-Filter).
His effort collecting and presenting practical Diablo II navigation knowledge
provided the inspiration and a highly useful reference for this independent
D2RLoader adaptation. Sincere thanks to Kryszard for making that work publicly
available.

Map Assistance uses original implementation and wording for D2RLoader. It is
not affiliated with, maintained by, or endorsed by Kryszard or Project Diablo
2. Refer to the upstream repository for its own authorship and license terms.
