# Item Roll Ranges development

The [player README](README.md) and [changelog](CHANGELOG.md) describe the shipping
plugin. Current implementation and guards are in `src/`; regressions are in `tests/`.

Read the [topic map](docs/README.md) for formatter, provider, contribution and
controller contracts. Use [CONTRIBUTING.md](../../CONTRIBUTING.md) for builds
and CTest; CMakeLists.txt defines the actual targets.

Preserve original property text, bounded formatting and ambiguous attribution.
Ranges come from active definitions and supported provenance; never invent a
bound or source label to fill a gap. Native profiles are build-specific.

[Historical records](docs/history/README.md) retain revision-specific captures,
validation and older behavior. They are evidence pointers, not current version declarations.
