# Item Roll Ranges reverse-engineering evidence

This directory contains derived formatter, provider, property-handler, and
contribution-path evidence used by Item Roll Ranges. Files were moved out of the
plugin root during the GitHub migration so build inputs and analysis records are
clearly separated.

These records are build-specific. Cross-check `provider-audit.json`, the active
compatibility constants in `src/`, and the top-level reverse-engineering
registry before reusing an RVA or layout.
