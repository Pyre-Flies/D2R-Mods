## Test boundaries and remaining work

Expanded group alternatives are tested individually for isolation; this does
not prove selection or conditional eligibility. Sentinel isolation uses a
synthetic disjoint stat deliberately; it does not assert every real shared
resistance/skill/ED combination. Reference tags test the same operation under
three source models, not three new independent captured game datasets.

Function2 bounds use the active property operands. Functions13/14 were measured
as unsupported by the generic range model and are not counted as successes.
Existing socket-header tests check placement and preservation, not the full
native item-level capacity function. Native clamping/durability transformation,
conditional set activation and recipe attribution remain explicit gaps.
