# Security and compatibility reports

Please open a private GitHub security advisory for memory-safety issues,
unexpected code execution, or vulnerabilities that should not be disclosed in
a public issue. Ordinary crashes, signature mismatches, and game-build
compatibility reports may use the compatibility issue form.

Include the plugin version, D2R and D2RCore file hashes, D2RLoader version,
reproduction steps, and the smallest relevant log excerpt. Do not upload game
binaries, account data, save files, or credentials.
